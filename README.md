# سامانه مدیریت ارتباط با مشتری (CRM)

رابط کاربری فارسی و راست‌چین (RTL) برای مدیریت ارتباط با مشتری، ساخته‌شده با
React، JavaScript (JSX)، Vite و Tailwind CSS.

## ماژول‌ها

| ماژول         | مسیر             | توضیح                                             |
| ------------- | ---------------- | ------------------------------------------------- |
| داشبورد       | `/`              | نمای کلی شاخص‌ها، روند فروش و فعالیت‌ها           |
| روند پیگیری   | `/follow-ups`    | مراحل پیگیری مشتری از تماس اولیه تا قرارداد       |
| گزارش‌ها      | `/reports`       | گزارش‌های تحلیلی فروش، مشتریان، عملیات و پشتیبانی |
| تحویل کالا    | `/deliveries`    | پیگیری سفارش‌ها از آماده‌سازی تا تحویل            |
| تعمیرات       | `/repairs`       | پرونده‌های تعمیر، تکنسین و برآورد هزینه           |
| بازاریابی     | `/marketing`     | سه زیربخش: کوره، سیستم جمع‌آوری، باسکول           |
| پشتیبانی      | `/support`       | تیکت‌های مشتریان و سنجش رضایت                     |
| ثبت مشتری     | `/customers/new` | فرم ثبت مشتری جدید                                |
| فهرست مشتریان | `/customers`     | فهرست مشتریان ثبت‌شده                             |

## اجرا

```bash
npm install
npm run dev      # سرور توسعه روی http://localhost:5173
npm run build    # خروجی تولید در پوشه dist
npm run preview  # پیش‌نمایش خروجی تولید
npm run format   # قالب‌بندی کدها با Prettier
```

برای تست روی موبایل، سرور با `--host` اجرا شود و از طریق آدرس شبکه
(مثلاً `http://192.168.1.102:5173/`) روی گوشی باز شود:

```bash
npx vite --host 0.0.0.0 --port 5173
```

## ساختار پروژه

```
src/
├─ components/
│  ├─ shared/      # ویجت‌های مشترک (کارت آمار، نشان وضعیت، نمودار، سرصفحه)
│  └─ ui/          # اجزای پایه (دکمه، کارت، نشان، فرم، جدول، تب، آواتار، مودال)
├─ config/         # تنظیمات منوی کناری
├─ data/           # داده‌های نمونه هر ماژول
├─ hooks/          # هوک‌های سفارشی (فیلتر، تم)
├─ layouts/        # چیدمان اصلی: سایدبار، نوار بالا
├─ lib/            # توابع کمکی (کلاس‌ها، اعداد و تاریخ فارسی، خروجی CSV)
├─ pages/          # صفحات هر ماژول
├─ router/         # مسیربندی برنامه
└─ store/          # استور مشترک داده‌ها (DataProvider)
```

## قابلیت‌ها

- **ثبت و ویرایش رکورد:** همه ماژول‌ها دکمه «جدید» برای ثبت و دکمه ویرایش (✎)
  در هر سطر جدول دارند. فرم ویرایش همان فیلدهای فرم ثبت است و وضعیت (status)
  را نیز قابل تغییر میکند. تغییرات در `DataProvider` ذخیره و بدون نیاز به
  بارگذاری مجدد صفحه نمایش داده میشود.
- **حالت روشن و تاریک:** دکمه تغییر تم در نوار بالا، در `localStorage` ذخیره
  میشود و همه رنگ‌ها با توکن‌های CSS در تم تاریک هم خوانا میمانند.
- **اعتبارسنجی فیلدهای عددی:** شماره تلفن (۱۱ رقم) و کد ملی (۱۰ رقم) فقط عدد
  میپذیرند و از عبور از طول مجاز جلوگیری میشود؛ فیلدهای درصدی (پیشرفت، امتیاز)
  به بازه ۰ تا ۱۰۰ محدود میشوند و در صورت کمتر بودن مقدار لازم، پیام خطا
  نمایش داده میشود.
- **خروجی اکسل:** در صفحات داشبورد و تحویل کالا خروجی CSV سازگار با اکسل
  فارسی دانلود میشود.
- **ریسپانسیو:** سایدبار در موبایل کشویی میشود، ستون‌های کم‌اهمیت جدول در
  نمایشگر کوچک پنهان و تبهای وضعیت در چند سطر میتوانند قرار بگیرند.

## تم و رنگ‌ها

رنگ‌ها به‌صورت توکن CSS در `src/index.css` تعریف شده‌اند و از طریق
`tailwind.config.js` در دسترس کلاس‌ها قرار می‌گیرند. برای تغییر رنگ برند فقط
مقدار `--brand` و برای تغییر رنگ سایدبار مقدار `--sidebar` را ویرایش کنید.

- سرمه‌ای تیره (`--sidebar`) برای نوار کناری
- فیروزه‌ای (`--brand`) برای دکمه‌ها و حالت فعال
- سفید و آبی بسیار روشن برای پس‌زمینه محتوا
- توکن‌های متن: `--foreground` (متن اصلی)، `--muted-foreground` (متن کمکی)،
  `--faint` (متن کم‌رنگ) و `--muted` (سطح خاکستری) که در تم تاریک هم
  به‌طور خودکار روشن میشوند. از همین رو در کدها به‌جای `text-slate-800` از
  `text-foreground` استفاده شده است.

## نکته

داده‌ها در پوشه `src/data` به‌صورت نمونه (mock) نگهداری می‌شوند؛ برای اتصال به
بک‌اند کافی است همین لایه‌ها با فراخوانی API جایگزین شوند. استور `DataProvider`
هم تنها نقطه تغییر برای این کار است.
